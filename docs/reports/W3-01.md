# W3-01: CC0 asset download pipeline with licence audit trail
**Files:** `tools/assets.json` (manifest, 42 entries from T-006), `tools/fetch-assets.mjs` (Node 24, zero npm packages),
`tools/assets-manifest.json` (audit trail, one entry per file fetched), `CREDITS.md` (generated), `.gitignore` (+`.claude/worktrees/`).

## How to run (from the project root)
- `node tools/fetch-assets.mjs --dry-run` — **start here**: resolves every id, asserts CC0 on the source, prints sizes, writes nothing.
- `node tools/fetch-assets.mjs` — full fetch (40 assets, ~264 MB). `--only id,id` / `--category terrain` for subsets.
- `--include-optional` adds `fir_tree_01` + `pine_tree_01` (1.35 GB, see below). `--credits` regenerates `CREDITS.md`; run after every fetch.
- Flags: `--force` (re-download), `--keep-raw` (keep `.cache/dl/<id>/`), `--max-bytes <n>` (cap, default 2 GB), `--manifest <path>`.
Safety: CPU < 50 % (PowerShell `Get-CimInstance`), 3 files in flight, 3 retries with 1/2/4 s backoff, running total + cap; each file is
checked for HTTP status, API size, Content-Length, API md5 (Poly Haven) and magic bytes; non-zero exit on any failure or licence rejection.
**Resolution policy** (in `assets.json`): 2k for terrain tiles and large architecture (18 textures + `large_castle_door`); 1k for everything else.

## Findings and decisions beyond the spec
- **Poly Haven's API has no licence field** (`/info`, `/assets`, OpenAPI schema checked). Each asset *page* carries schema.org JSON-LD with
  `license = https://creativecommons.org/publicdomain/zero/1.0/` and `copyrightNotice = "CC0 1.0 Universal ..."`; both must match or the asset
  is rejected. Poly Haven's llms.txt asks tools to prefer the API; one page read per asset is the minimum that satisfies D-004.
- Poly Haven models ship as `.gltf` + `.bin` + `textures/*.jpg`, never `.glb`, so they land in `assets/models/<category>/<id>/` (Godot imports
  `.gltf` natively). Poly Pizza animals are single `.glb` at `assets/models/animals/<name>.glb`. `.bin` has no magic bytes: size + md5 only.
- **`fir_tree_01` (465 MB) and `pine_tree_01` (914 MB)** are scanned whole trees; marked `optional` (resolved + licence-checked every run,
  fetched only with `--include-optional`). D-002 makes trees procedural, so they are hero-tree fallbacks. Full set with them: ~1.6 GB.
- Poly Pizza: licence from the page's embedded `"Licence":"CC0 1.0"`, title/author from `"Title"`/`"Creator"`, size from a HEAD `Content-Length`
  (no md5 offered; sha256 recorded). T-006 has 4 animals, not 5; the goat is CC-BY and excluded (confirmed live in test 5).
- **Freesound needs an API key / OAuth2 token** (`/apiv2/sounds/201811/` → `401 Authentication credentials were not provided`; site download
  link 404s without login). Audio is out of the manifest. Owner action: create a Freesound API key, then audio can be added.
- Extras: `--include-optional`, `--manifest`, `node:child_process` for the CPU check (built-in), missing map = warning, dry-run skips the CPU check.

## Gaps (honest)
- Poly Pizza parsing is regex over page markup; a redesign breaks it (fails with a message naming the regex, never downloads blindly).
- Skip detection compares sizes only (sha256 is in the audit manifest); the licence is still re-asserted on every run. Cap is per run, no `du` check.
- Nothing imported into Godot yet; optional trees never test-fetched; boulders at 1k may need 2k (edit `resolution`, rerun with `--force`).
