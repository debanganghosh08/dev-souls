**Interactable API** (`extends Area3D`, layer 3 `interactable`, mask 0 — detected, never detects):
exports `id: StringName` · `prompt = "Examine"` · `once_flag` · `required_item` · `consumes_item = false` · `required_flag` · `sets_flag` ·
`toggles_flag = false` (set/clear `sets_flag` alternately — levers) · `refusal_text = "It does not yield."` · `need_item_text = "You need the %s."` ·
`glow_range = 6.0`. Signals `interacted(who: Node)`, `refused(reason: String)`. Methods `is_spent()`, `can_interact()` (spent → required_flag →
required_item), `refusal_reason()` (spent/flag → refusal_text; missing item → need_item_text % Inventory name, else refusal_text), `prompt_text()`
("" when spent), `interact(who) -> bool` (refuse | consume item → `_on_interact(who)` → set/toggle sets_flag → set once_flag → `interacted` → autosave),
virtual `_on_interact(who)` (no flag/item work there), virtual `set_focused(bool)` (default drives `%Glow` emission), `_inject(flags, inventory, save)`
(autoloads via `/root/...` in `_ready`; any may be null → feature degrades, never crashes), helper `_pose(node, prop, value, secs)` (tween in-tree, snap otherwise).
Subclasses: `Chest.contents: Dictionary` (+`%Lid`), `Pickup.item/amount` (hides + `monitorable=false`), `LoreStone.lore_key` → `reading_requested(title, body)`,
static `LoreStone.lore_entry(key)`, `Lever.is_on()` (+`%Handle`), `Door.locked_flag/open_angle_deg/open_time`, `is_open()` (+`%Leaf`, `%Blocker` StaticBody3D).

**InteractionDetector API** (`extends Area3D`, child of the player; sphere of `max_range` built in `_ready`, mask = interactable only):
exports `max_range = 3.2` · `max_angle_deg = 75` · `camera_path`. Signals `focus_changed(target: Interactable)` (on change only, incl. null),
`interaction_refused(reason)`. `current_target()`, `try_interact() -> bool` (passes `get_parent()` as `who`), `interact` action handled in `_unhandled_input`
while `Game.state == PLAYING`. `static score(angle_deg, distance, max_angle, reach) -> float`: −1 if beyond reach/cone, else
`0.8·(1 − angle/max_angle) + 0.2·(1 − distance/reach)`; angle is from the camera's position along its forward (screen-centredness), distance from the detector.
Candidates are kept via `area_entered/exited` (no per-frame allocation); `prompt_text() == ""` candidates are skipped.
