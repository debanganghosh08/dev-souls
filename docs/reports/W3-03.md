# W3-03 — procedural tree generator, materials and forest placement

**Twig atlases, actually inspected.** Both 1024×1024 RGB8; the alpha PNG is a white-on-black mask (white = needle).
They are **not grids** but the photoscans' UV layouts. `fir_tree_01_twig`: 7 usable sprays scattered over the centre,
an opaque bark strip down x 0–210 and an opaque branch along the bottom/right. `pine_tree_01_twig`: ~65 % opaque
cone/bark islands and only **2** sprays on black (x 38–224 / y 46–452 vertical; x 668–958 / y 350–530, stem left).
Method: flood-filled the masks headless with Godot `Image`, took each spray's bounding box, counted pixels of the big
opaque islands inside every candidate rect and trimmed until that count was 0 (pine A lost its bare stem below y 386,
pine B its top-left corner). Rects live in `data/trees.json` as pixel `atlas_cells` + `stem` edge; TreeGen puts the
card's trunk end on that edge, keeps the rect's pixel aspect (no stretching), mirrors U at random; `atlas_grid` is only a fallback for a real grid atlas.
**API.** `TreeGen.build(params, seed) -> {trunk, cards, height, radius, collider_radius}`, `params_for`, `archetypes`,
`lod_params(params, level)`. `TreeParams` (split out to keep treegen.gd < 250 lines): `load_file`, `merge_over_base`,
`reset`. `TreeMaterials.bark_for/cards_for(name)`, `clear_cache`. `Forest`: spec exports + `chunk_size`; `rebuild`,
`tree_count`, `stats`, `positions`, `layout_hash`, static `plan_layout` (pure, tested without a scene).

**Decisions beyond the spec.** Cards use a 20-line `ShaderMaterial` (`scripts/systems/twig_card.gdshader`), not
`StandardMaterial3D`: Standard has no separate alpha-texture slot and `_diff` is a JPEG, so the shader samples
`_alpha` into `ALPHA` with `ALPHA_SCISSOR_THRESHOLD 0.5`, `cull_disabled`, `diffuse_lambert`, `specular_disabled`.
One winding per card (double-sided via cull) so card verts = whorls×branches×4. Trunk via `add_surface_from_arrays`
(explicit vertex order makes the first/last-vertex test meaningful). Card normals bend to outward+up. Missing
textures fall back to flat colours. **LOD/culling actually done:** instances grouped into 40 m chunks; per
chunk×archetype a trunk MultiMesh (0–`cull_distance`), a full card MultiMesh (0–`lod1_distance`) and a reduced one
(half whorls, 60 % branches, cards ×1.35; `lod1_distance`–`cull_distance`) via `visibility_range_*`, which Godot
evaluates per node: the switch is per chunk, not per tree. 200 trees → 68 multimeshes. **Colliders:** only the
`collider_count` nearest-to-origin trees get a `CylinderShape3D` StaticBody3D on layer 1; every other tree is
walk-through until a streaming task moves colliders with the player.
