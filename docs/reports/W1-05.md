# W1-05 — main menu, HUD, lore cards, death screen, pause and settings
**Layout** (branch `task/W1-05`): `scripts/main.gd` + `scenes/main/main.tscn` (entry point, now `run/main_scene`); `scripts/ui/{ui_text,ui_util,
settings,hud,item_toasts,lore_card,death_screen,pause_menu,settings_panel,main_menu}.gd`; `scenes/ui/{hud,lore_card,death_screen,pause_menu,
settings_panel,main_menu}.tscn` + `souls_theme.tres` (one shared Theme, no fonts or images); `data/ui_text.json` (every string; `UiText.text(key)`
falls back to built-in English with `push_error`); `tests/test_settings.gd` (8, pure) + `tests/test_ui.gd` (6, incl. child `--probe`). Edited: `greybox.gd`
(pause/respawn keys removed, readout behind F3, probe only when root scene), `player.tscn` (group), `project.godot` (`run/main_scene`). `TASKS.md` untouched.

**How `main.gd` composes things** — `Main (Node)`: `%LevelRoot (Node3D)`, `%Overlays (Node)`, `%MainMenu`, `%Loading`. `_ready` loads+applies
`GameSettings`, `Game.state = MENU`, opens the menu. **`_begin_level(path, continue_save)` is the single loading entry** (`load_threaded_request`,
polled in `_process`, "Awakening…" meanwhile) → `_enter_level(scene)`: level under `%LevelRoot`, HUD / death screen / pause menu under `%Overlays`,
`hud.bind_player` (group `player`), `hud.bind_level(level)` (connects every `LoreStone.reading_requested`), state PLAYING; Continue runs
`SaveGame.load_slot()` *after* the level is in the tree, then moves the player to `Game.player_position`. `_leave_level` frees level + overlays →
MENU. **To ship a real area change `LEVEL_PATH` (or pass another path to `_begin_level`); nothing else cares.** HUD = CanvasLayer 1 (stamina bar
fades to 12 % after 2 s full; `[E]  Open` prompt; refusal 2.5 s; ≤3 toasts `Acquired — name ×N`; lore card is a sibling of the overlay so it survives
the overlay hiding on PAUSED). Death = layer 10: Tween 1.2 s in → hold 1.5 s → `Game.respawn()` → 0.8 s out, `safety_sec = 6` hard clear, also on
MENU. Pause = layer 20, ALWAYS, opens only from PLAYING (a lore card holds PAUSED, so never over a card nor when DEAD); Save and Quit → `SaveGame.save()`
→ `quit_to_title_requested` → `main._leave_level`.
