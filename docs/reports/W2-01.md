# W2-01 — day/night cycle, sky profiles, atmosphere
**Built:** `scripts/systems/sky_profile.gd`, `scripts/systems/daynight.gd`, `data/daynight.json`, `scenes/environment/sky.tscn`,
`scenes/levels/skytest.tscn` + `.gd`, `tests/test_sky_profile.gd` (9), `tests/test_daynight.gd` (8). Nothing else touched.
**API — `SkyProfile` (RefCounted, pure).** `static from_dict(data) -> SkyProfile` (shape: `{"keyframes": [{"hour", "sun_color",
"sky_top", "sky_horizon", "ground_color", "fog_color", "fog_density", "sun_energy", "ambient_energy", "star_alpha"}]}`; colours are hex
strings or `Color`s, bad/missing values fall back to `SkyProfile.DEFAULTS`, non-dict entries skipped) · `add_keyframe(hour, values)` ·
`keyframe_count()` · `keyframe_hours() -> Array[float]` · `sample(hour) -> Dictionary` with the nine keys, hour wrapped with `fposmod`,
interpolation wraps the short way across midnight. 0 keyframes → `DEFAULTS`; 1 → that frame everywhere; input sorted on insert.
**API — `DayNightCycle` (Node, root of `sky.tscn`).** Exports: `minutes_per_day` 20 · `paused` · `area` `&"vale"` · `start_hour` 8
(negative = leave `Game.time_of_day` alone) · `environment_path` / `sun_path` / `moon_path` · `sun_yaw_deg` 25 · `moon_energy` 0.12 ·
`moon_color`. Methods: `set_area(id)` (re-applies at once; unknown id warns and uses vale) · `current() -> Dictionary` (last sample) ·
`hour()` · `sun_is_up()` (sun elevation strictly between 0° and 180°, i.e. just after 06:00 until just before 18:00) · `area_ids()` ·
`static load_profiles(path) -> Dictionary[StringName, SkyProfile]` · `_inject(game)` for tests. `_process` calls
`Game.advance_time(delta * 24 / (minutes_per_day * 60))` only while `Game.state == PLAYING` and not paused. On `Game.time_changed`
it repaints only when the hour moved ≥ 0.01 h. Sun: `rotation_degrees = (-elevation, yaw, 0)`, 06:00 → 0°, 12:00 → -90°, 18:00 → -180°;
below the horizon it is `visible = false`, energy 0, shadows off. Moon: opposite rotation, visible + shadows only while the sun is down,
energy `moon_energy * star_alpha`. Sky material: top/horizon from profile, `ground_horizon_color` = fog colour, `ground_bottom_color` =
ground colour. Environment: `fog_light_color`, `fog_density`, `ambient_light_color` = sky horizon, `ambient_light_energy`.
**Palettes (`data/daynight.json`, 9 keyframes each at 0, 4.5, 6.5, 9, 12, 15, 17.5, 19.5, 22):** vale = desaturated grey-blue, fog
0.030–0.042, noon sun 0.78, night ambient 0.14 · wood = green-black, fog 0.060–0.080, noon sun 0.36, night ambient 0.12 ·
barrens = rust/dust, fog 0.008–0.020, noon sun 1.15 warm, cold blue-black night ambient 0.11.

**Decided myself:** ambient source is COLOR (profile-driven, numbers readable) not SKY radiance · `Sky.process_mode = INCREMENTAL` so
material edits do not stall a frame regenerating radiance · `star_alpha` has no star layer yet, it only scales the moon · sun light is
switched off below the horizon (profile `sun_energy` at 06:00/18:00 still tints the sky; the disc clears at ~06:01) · `start_hour`
writes the Game clock on `_ready` · skytest keys use raw keycodes (T/H/P/Esc) so `project.godot` stays untouched · in-process tests
call `_ready()` on an out-of-tree instance with an injected `game.gd`, the same trick as `test_player.gd`.
**Gaps / untested (headless has no GPU — nobody has seen any of this):** every colour, fog, glow, tonemap white and shadow value is a
first guess; "dark but silhouettes readable" is asserted only as ambient > 0. Torch/HUD hook is `current()`, not built. No stars, moon
disc, clouds or rain. Sun disc follows the visible light only (no pre-dawn glow). Fixed yaw. Area switch is a hard cut. TASKS.md untouched.
